# Identidad visual de Flow

El símbolo de Flow se construye con cinco barras verticales redondeadas y
monocromas. La variación simétrica de altura recuerda a una `W` y a una señal
de voz sin añadir detalles que se pierdan al reducirlo.

- `flow-mark.svg`: símbolo vectorial transparente para interfaces y composiciones.
- `flow-icon.svg`: versión de aplicación con fondo blanco redondeado.
- `Export-FlowLogo.ps1`: genera los recursos PNG e ICO de Windows a partir de
  la misma geometría.

Android usa el VectorDrawable
`Flow.Android/app/src/main/res/drawable/flow_logo.xml`, por lo que el icono
principal no depende de un bitmap.
